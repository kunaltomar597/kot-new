# apps/table-tablet: customer table tablet (C6)

React Native + Expo, Android kiosk (device-owner lock-task under MDM), bound to one table. Idle screen,
menu, search, recommendations, ordering with waiter approval, Water/Waiter/Bill/Cancel, live status,
feedback. Wipes all session data when the table closes.

Built by: P2-01 (foundation), P3-01 to P3-06, P6-03 (voice). Not started yet.
