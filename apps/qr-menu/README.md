# apps/qr-menu: QR online menu (C7)

Next.js public, mobile-first site opened from a per-table QR code. Reads the menu snapshot from the
cloud relay and submits dine-in orders through relay edge functions (never writing tables directly).
No login, no tracking, read-only when the restaurant is offline.

Built by: P5-05. Not started yet. Performance budget: LCP ≤ 2.5 s on a mid-range phone over 4G.
