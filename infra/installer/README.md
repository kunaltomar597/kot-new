# infra/installer: Windows installer, services and watchdog (C12)

Scripts and definitions for the signed Windows installer: bundled Node runtime and server build,
Windows service wrapper (WinSW or equivalent), bundled PostgreSQL 16 service on the chosen data
drive, watchdog, firewall rules, DPAPI secret store, data-drive selection (ONB-002).
