# BRD

- `Restaurant_Platform_BRD_v1.0.pdf`: the Business Requirements Document v1.0. Authoritative.
- `brd-v1.0.txt`: plain text extracted from the PDF (Unicode NFKC normalised) for searching.
  Tables and diagrams are flattened.
- `requirements.json`, `requirements.md`: every requirement ID with priority, section and text,
  generated by `pnpm brd:catalog`. Do not edit by hand.

When a new BRD version arrives: replace the PDF, re-extract the text, run `pnpm brd:catalog` and
`pnpm trace`, and record the changes in `docs/build/PROGRESS.md`.
