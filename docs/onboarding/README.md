# Onboarding material

Files the vendor gives a restaurant during onboarding (BRD §7, ONB).

- `menu-template.xlsx`: the menu import template (ONB-005). It has sheets Items, Variants,
  Modifiers and Combos, each with a header row and a notes row saying what goes in each column.
  It is generated by `pnpm --filter @rp/server build && pnpm --filter @rp/server menu:template`.
  Managers can also download it from the server (`GET /api/v1/menu/import/template`). Import it
  with `POST /api/v1/menu/import/check` (report only), then `POST /api/v1/menu/import`.
