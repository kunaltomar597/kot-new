# ETSI EN 303 645 (the wrist pager)

BRD §8.1: the ESP32-S3 wrist pager meets the ETSI EN 303 645 baseline for consumer IoT (no default
passwords, secure updates, secure storage). Written in P8-03d2b2d (2026-10-11).

The pager's firmware is written in P2-05, which needs a person with the hardware ([H]). So each
provision has two sides: **the PC's side**, built and tested (the broker, the credentials, the
firmware pipeline), and **the pager's side**, which is a Finding with its plan until the firmware
exists. The checks of P2-05 turn those findings into Met with the firmware's code and tests.
Statuses and evidence as in [README](README.md); the [threat model](../threat-models/pager-channel.md)
analyses each point.
