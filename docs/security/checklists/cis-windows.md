# CIS for the Windows host

BRD §8.1: the restaurant PC follows a hardening checklist based on the CIS Microsoft Windows 11
Benchmark (service accounts, firewall, BitLocker). Written in P8-03d2b2d (2026-10-11).

The benchmark has hundreds of settings for a general office PC. This checklist keeps the groups
that matter for a restaurant PC that runs the POS and the server, and says for each who does it:
the installer (checked by its Pester tests in the `windows-latest` CI job), the software (a warning
or a check on the System page), or a person (the runbook, and manual task 35 for the checks on a real
PC). Statuses and evidence as in [README](README.md). The runbook is
[the PC as a computer](../../runbooks/windows-host.md); the
[threat model](../threat-models/local-server-and-lan.md) analyses each point.
