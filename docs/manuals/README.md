# User manuals and training material

One manual per role, written in plain language for the people who use the system (BRD §19.3,
NFR-U07). What each role may do follows the permission matrix (`packages/domain` permissions,
BRD §4.2); where a manual and the matrix differ, the matrix wins and the manual is wrong.

- `owner.md`, `manager.md`, `cashier.md`, `waiter.md`, `kitchen.md`
- `training-video-scripts.md`: scripts for the training videos. The Business Owner approves each
  script before it is filmed (BRD §19.3). Videos are recorded by a person; Claude cannot film.
- In-app help: every dashboard page has a Help button and a first-use tip (P8-04b).
- The usability test scripts in `docs/usability/` were written against these tasks.
