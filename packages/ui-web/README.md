# @rp/ui-web

React component library for the console (POS, KDS, dashboard) and QR site: PinPad, NumberPad,
buttons, dialogs, toasts, status chips, money display, empty/loading/error states, connection banner,
and the shared menu item card and variant/modifier/combo selection components (MENU-012).
Built by: P0-13, extended in P1-08. Not started yet.
